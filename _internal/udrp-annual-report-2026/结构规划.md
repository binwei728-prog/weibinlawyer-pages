# 《2026 中国相关 UDRP 案件年度观察》· 结构规划

> 本文件不对外发布（位于 `_internal/`，Jekyll 构建时排除）。
> 本轮只出架构，不采集数据、不发布报告。发布前须先完成数据采集与逐条核对。

## 一、报告定位

面向企业法务、品牌与知识产权负责人、境外代理机构，用可核对的数据说明中国相关主体在 UDRP 程序中的实际处境：哪些路径更常被采用、哪些争点反复出现、哪些做法容易导致不利结果。

**不做什么：**

- 不做律所或代理人排名
- 不做"胜诉率排行榜"
- 不做超出样本本身的趋势断言
- 不发布无法溯源到具体案件编号的统计数字

## 二、"中国相关案件"的界定（发布前必须先在报告中写明）

口径模糊会直接导致数字不可比。建议采用**并列式口径**，逐案标注命中了哪几条，统计时同时给出合计与分项：

1. 投诉人或被投诉人为中国境内注册的主体
2. 争议域名对应的商标权利人为中国境内主体
3. 程序语言为中文，或当事人提交中文材料
4. 争议域名涉及中文品牌、中文通用词或拼音组合
5. 被投诉人所在地为中国境内（以投诉提交时 Whois 记载为准）

**口径声明写法示例：** 本报告所称"中国相关案件"，指在下列任一口径上与中国境内存在关联的案件：……。由于各机构的公开检索条件不统一，样本为该口径下可公开检索到的裁决，不等于该年度全部案件。

## 三、数据来源与可追溯要求

| 项目 | 要求 |
|---|---|
| 来源 | 五家 ICANN 认可机构官方网站公布的裁决全文 |
| 检索方式 | 各机构官方检索系统，按日期区间 + 关键词 / 当事人等条件组合检索 |
| 原始记录 | 每条案件保存：案件编号、官方 URL、检索日期、核对人 |
| 附录 | 报告必须附"案件清单"附录，逐条列出案件编号与官方链接 |
| 复核 | 统计完成后，抽取不少于 10% 的样本重新打开官方页面二次核对 |
| 不可得说明 | 无法公开检索的部分，在报告中明确说明为样本外，不估算、不补值 |

**数字规则：** 报告中出现的每一个数字，都要能回答"这个数字是从哪几条案件算出来的"。

## 四、统计维度

### 4.1 数量与分布
- 案件总数，按机构分布
- 按裁决月份 / 季度分布
- 与上一年度的可比区间对比（若有可比数据）

### 4.2 域名特征
- 顶级域分布（含 `.ai` 单列）
- 域名字符构成：是否含通用词、是否含数字、是否含连字符、是否为拼音组合
- 域名标签长度区间
- 单案争议域名数量分布

### 4.3 当事人与代理特征
- 投诉人类型：企业 / 个人 / 其他主体
- 被投诉人类型及是否委托代理人
- 是否出现同一投诉人的多案（批量投诉）情形
- 代理机构所在地分布（不下沉到具体机构名称）

### 4.4 程序特征
- 专家组组成：一人组 / 三人组
- 程序语言
- 是否提交答辩（答辩率）
- 是否申请四日自动延期、是否申请例外延期
- 是否存在异议意见
- 从程序开始日到裁决日的时长分布

### 4.5 结果分布
- 转移 / 注销 / 不支持投诉 / 部分支持 / 程序终止
- 结果与专家组组成、答辩率、域名字符构成之间的交叉分布

### 4.6 三项要件认定分布
- 逐项统计 upheld / failed / not-reached
- 要件未获支持时，卡在哪一项的分布

### 4.7 第 4(c) 条抗辩
- 三种典型情形各自的援引频次与获认定频次

### 4.8 RDNH
- 认定 RDNH 的案件数量、机构分布
- 认定理由的类型归纳（只归类，不点名评价当事人）

### 4.9 裁决后程序
- 可公开查到的、当事人于相互管辖法院起诉的情形
- **可得性限制必须写明：** 此类信息通常不在机构页面披露，若无可靠来源，本项不作为统计项，只作定性说明。

**图表要求：** 不使用渐变背景；涨跌类表达遵循中文财经惯例；所有图表标注数据来源与样本量。
