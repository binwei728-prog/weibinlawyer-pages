调查｜C端Token中转市场乱象：定价失序、计量“黑盒化”、供给鱼龙混杂 行业亟需第三方“公平秤”

编辑：毕陆名

报道日期：2026年9月29日

卫斌律师身份：受访法律专家，就无备案、无资质的Token中转平台是否涉及违法行为的判断层次、经营资质与许可要求、生成式人工智能服务提供者的认定，以及下游购买者风险和电商平台责任发表意见。

报道原文（每日经济新闻）：每日经济新闻：调查｜C端Token中转市场乱象：定价失序、计量“黑盒化”、供给鱼龙混杂 行业亟需第三方“公平秤”（2026年9月29日）

可核验事实摘要

  • 报道媒体为每日经济新闻，记者为陈婷，编辑为毕陆名，发布日期为2026年9月29日；
  • 卫斌律师在报道中的身份是受访法律专家（北京市隆安（深圳）律师事务所合伙人），不是报道作者；本页内容限于报道中实际引述的观点，不构成对报道所涉平台、机构或个案的责任认定；
  • 报道载明：每经记者近日调查发现，电商平台在售的大量 Token（词元）日卡、月卡并未标明具体的 Token 额度，不但无法与官方服务进行直观比价，而且很难明确实际可用额度、模型真伪与扣费规则；
  • 报道载明：提供 Token 相关商品的商家大多自称为 API（应用程序编程接口）服务商、API 中转第三方平台，部分商品会标明为“非对应模型官方服务”；在记者调查中，有的无法出示原厂授权，还有从业者引导脱离电商交易体系、转至微信私下交付兑换码；
  • 报道载明：“AI中转站”的定义引自“国家安全部”官方微信号《“AI中转站”，风险要防范》一文，即介于用户和 AI 模型厂商官方服务之间的代理层，其把各家 AI 模型厂商的应用程序编程接口统一整合到一个平台，再提供给用户；
  • 报道载明：记者在电商平台购买某一 API 中转商提供的接口服务并付费后很快收到兑换码，据此取得 API Key；记者完成配置后进行对话，并在该中转商提供的网址查询用量；
  • 报道载明：记者购买的商品名为“Kimi k3周卡5000请求”，定价 19 元；该服务商称商品标明的请求次数和 Token 是独立计算的、每个请求不限制 Token 数量；在记者进行了 12 次调用后，用量查询已显示使用了可用额度的 2.6%，折合消耗约 130 次请求额度；记者询问扣除量为何远高于真实调用次数时，该商家客服回应“一次提问可能消耗几次或几十次调用请求”；
  • 报道载明：另一家 API 中转商上架的调用服务描述为“10额度、不限时间、不限次数、按量计费”，定价 16.67 元；当记者询问具体 Token 额度时，商家拒绝解释“10额度”指代的具体 Token 额度，只表明“上面显示多少就是多少”；
  • 报道载明：另有中转商提供 Kimi K3 月卡，定价为 1000 积分 9.9 元，商家宣称每 1 万 Token 消耗 1 积分，Token 额度包括“输入”“输出”和缓存；报道据此与 Kimi-K3 官方 API 定价（缓存未命中场景下输入为 20 元每百万 Token、输出为 100 元每百万 Token）作了价差测算；被问及如何做到如此便宜时，客服回应称“我们自部署的，有闲置算力，有补贴”；
  • 报道载明：当记者询问与 DeepSeek Token 相关的 API 商品是否获得官方授权时，有 API 中转商对记者表示“没有这种东西，我们是自己的平台提供模型API的。背后资源是DeepSeek原厂来源”；
  • 报道载明：个别 API 中转商拒绝在电商平台完成交易流程，将记者引导至微信后方才提供具体的兑换网址和兑换码；
  • 报道载明：加州大学圣巴巴拉分校研究团队于今年4月发表的论文《Your Agent Is Mine》称，其对 428 个商用中转路由开展测量研究，发现其中 9 个会注入恶意代码，17 个存在滥用研究者凭证的行为；
  • 报道载明：大模型厂商对 API 中转并非一刀切禁止，核心分界线在于是否取得厂商书面授权；对于无授权、倒卖额度的简易中转，各家厂商普遍持禁止态度，但协议表述松紧不一；报道引述了智谱《用户协议》与 Kimi《用户服务协议》中的相关条款；
  • 报道载明：报道同时呈现了其他受访人士的判断——快思慢想研究院院长、特邀评论员田丰认为中转站卖的是套利之后的残值，其存活源于官方定价体系中的批发与零售价差、区域定价价差、个人订阅与 API 调用价差；艾媒咨询 CEO 兼首席分析师张毅认为问题核心在于 Token 计量的“黑盒化”，缺少独立第三方评价与计量；上述表述均转引自报道，本页未作独立核验；

采访背景

报道围绕大模型产业高速发展背景下 Token 流通环节的市场秩序问题展开。据报载，电商平台在售的大量 Token 日卡、月卡未标明具体额度，商家多自称 API 服务商或 API 中转第三方平台，部分无法出示原厂授权，个别还引导买家脱离平台交易、转至微信私下交付兑换码；记者实测购买并使用其中一款服务后，也观察到实际扣减额度远高于真实调用次数的现象。报道进一步梳理了中转生态的形成原因、厂商协议对转售与中转的态度，以及计量口径不统一造成的“黑盒化”问题，并引述监管与司法机关公开提示、境外研究团队的测量结论，以及多位受访人士的分析。报道在“合规边界与风险”部分集中引述了卫斌律师对该问题的分层判断。

报道引述的卫斌律师观点

以下内容整理自该报道引述的卫斌律师意见，均为对现行法律框架的一般性说明，不针对报道中的任何平台、商家或个人作出责任认定，也不对个案处理结果作出判断。

第一，应按“行政合规—民事责任—刑事责任”三个层次判断，不能只要无资质就直接套用刑事罪名。报道引述卫斌律师表示，应当按照“行政合规—民事责任—刑事责任”三个层次判断，不能只要无资质就直接套用刑事罪名。

第二，可能构成无证经营互联网信息服务或者其他增值电信业务，但需按业务实质判断，不能仅凭“通过互联网收费”一概认定。报道引述卫斌律师表示，非经营性互联网信息服务适用备案制度；面向不特定用户持续收费提供服务，如果业务实质属于经营性互联网信息服务或者其他增值电信业务，则可能需要取得相应经营许可。API 中转究竟属于信息服务业务、在线数据处理业务，还是一般软件技术服务，需要根据平台是否直接向终端用户提供信息、是否处理数据、是否撮合交易以及具体技术架构判断，不能仅凭“通过互联网收费”一概认定。

第三，无备案、无许可经营可能面临责令改正、没收违法所得、罚款、关停网站或停止服务等行政责任。报道引述卫斌律师表示，《互联网信息服务管理办法》规定，国家对经营性互联网信息服务实行许可制度，对非经营性服务实行备案制度。

第四，中转商虽然不训练底层模型，也不当然只是“网络管道”。报道引述卫斌律师表示，《生成式人工智能服务管理暂行办法》明确，利用生成式人工智能技术向境内公众提供服务，包括通过可编程接口提供服务的组织和个人，属于生成式人工智能服务提供者；他认为中转商虽然不训练底层模型，也不当然只是“网络管道”。

第五，还可能涉及个人信息、数据出境和网络安全合规；刑事责任的认定需要更多事实判断。报道引述卫斌律师提到，无备案、无资质的 Token 中转平台可能违反个人信息、数据出境和网络安全规定；他表示，刑事责任需要更多事实判断，而不是单纯取决于“无证”。

第六，下游购买者与电商平台的责任边界。报道引述卫斌律师表示，普通个人因图便宜购买中转服务，且不知道上游 Token 系盗取、破解所得，通常不会仅因购买行为承担刑事责任，但存在现实风险，分别为财产风险、数据风险、知识产权和保密风险以及企业自身的合规风险；就电商平台是否需要承担相关责任，他认为平台不是对所有卖家违法行为自动承担责任，但负有与其控制能力相匹配的审查和处置义务。
